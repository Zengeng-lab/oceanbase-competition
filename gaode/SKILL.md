# 周边去哪玩推荐助手

## 功能描述
基于高德开放平台的周边探索智能助手，用户用一句话说出位置和需求，助手自动推荐合适的地点，并给出步行/公交路线指引。

## 核心能力
1. **需求理解**：自动解析用户输入里的位置、目的地类型、距离要求、偏好（比如"近一点"、"评分高"）
2. **地点查询**：调用高德POI搜索API查询符合要求的周边地点
3. **智能筛选**：按距离、评分、人均消费排序，优先推荐步行可达的地点
4. **路线规划**：调用高德路径规划API给出最优步行/驾车路线，预估到达时间

## 使用示例
**用户输入**：我在郑州大学主校区东门，想找一家步行不超过10分钟的咖啡馆，推荐2-3家就行
**助手返回**：
1. 瑞幸咖啡(郑大科技园店)：距离380米，步行5分钟，评分4.7，人均15元
   - 路线：从东门出发沿科学大道向东走280米，左转进入大学科技园就到
2. 幸运咖(郑大店)：距离620米，步行8分钟，评分4.5，人均8元
   - 路线：从东门出发沿长椿路向北走600米，路西就是

## 验收标准
✅ 能正确解析用户的位置、需求、距离约束
✅ 返回的地点都是真实存在的高德POI
✅ 路线指引清晰，步行时间估算准确
✅ 推荐数量符合用户要求，不冗余
