# Dify智能应用：大学生期末复习助手

## 应用简介
基于Dify搭建的大学生专属复习助手，结合seekdb向量数据库存储用户上传的课程课件、笔记，自动生成考点总结、模拟题，帮学生高效备考。

## 核心功能
1. **资料导入**：用户上传PDF课件、课堂笔记，自动存入seekdb向量库做切片索引
2. **考点总结**：根据上传资料自动生成本章节的核心考点，标注重点
3. **模拟出题**：自动生成选择、简答模拟题，附带答案解析
4. **错题本**：记录用户答题错误的题目，反复推送练习

## 技术结合
- 使用Dify可视化工作流编排整个对话流程
- 集成seekdb作为RAG向量检索层，所有课程资料都存在seekdb里
- 支持多轮对话，学生可以随时针对某个知识点提问

## 运行说明
1. 在Dify平台导入本应用的DSL配置文件
2. 配置seekdb的连接地址和API Key
3. 发布应用后，学生上传自己的课程资料即可开始使用

## 验证样例
- 用户上传《人工智能导论》课件，助手自动生成：
  - 核心考点：机器学习三要素、监督学习/无监督学习区别
  - 模拟题：解释什么是过拟合，如何解决
