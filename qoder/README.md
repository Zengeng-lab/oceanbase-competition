# Qoder项目：大学生竞赛资料检索助手

## 项目简介
使用Qoder智能体平台开发的大学生竞赛资料一站式检索助手，结合seekdb向量数据库存储各类学科竞赛的历年真题、获奖经验、报名指南，学生搜索竞赛名就能直接拿到所有相关资料，大幅节省找资料的时间。

## 核心功能
1. **竞赛资料检索**：输入竞赛名称（如"ACM"、"蓝桥杯"、"OceanBase大赛"），自动从seekdb里检索对应的报名时间、赛题、获奖经验贴
2. **智能推荐**：根据学生的年级、专业，推荐适合参加的竞赛
3. **官网链接直达**：每个竞赛条目都附带官网报名链接，点一下就能跳转

## 技术实现
- 整个项目使用Qoder进行全流程开发：从需求拆解到代码生成、测试、部署
- 使用seekdb存储所有竞赛资料的向量索引，支持语义搜索
- 通过Qoder Sites发布成公开可访问的静态网站，学生直接打开就能用
